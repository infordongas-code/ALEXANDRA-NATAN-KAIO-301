PORTFÓLIO — PROFESSORA ANA LURDES
=================================

Arquivos:
- index.html: estrutura do portfólio
- style.css: cores, layout e responsividade
- script.js: menu móvel, ano automático, impressão/PDF e cópia do modelo de contato
- img/ana-lurdes.jpg: fotografia fornecida

COMO ABRIR NO VS CODE
1. Extraia o arquivo ZIP.
2. Abra a pasta portfolio_ana_lurdes no Visual Studio Code.
3. Abra o arquivo index.html no navegador. Se tiver a extensão Live Server, clique em "Go Live".

PERSONALIZAÇÃO IMPORTANTE
O portfólio usa uma organização inspirada no currículo Lattes, mas não é um currículo Lattes oficial.
Como não foram fornecidos dados acadêmicos completos, os campos de formação, instituição, e-mail e link do Lattes são exemplos para preencher. Revise também as descrições de atuação para corresponder à experiência real da professora.
A fotografia está salva localmente em img/ana-lurdes.jpg.
